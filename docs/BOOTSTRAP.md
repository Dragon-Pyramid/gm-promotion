- /en

## Initial story
- Scene 00: identity / hero
- Scene 01: fragmentation problem
- Scene 02: transformation PoC

## Important
React Kino 0.6.0 existed in the benchmark source but was not yet the public npm
baseline used by this bootstrap. We start with the published 0.5.0 runtime and
upgrade intentionally after the PoC if/when the required 0.6 Story/Storyboard
release is available and verified.

## Engineering rule
One story. One owner of scroll. Many ways to render it.

## Media rule
Spectacular in perception, contained in weight:
poster-first, responsive assets, mobile variants, lazy loading and complete
reduced-motion fallbacks.
